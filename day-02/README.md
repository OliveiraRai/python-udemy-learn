Aprendizado de cálculos matemáticos no mundo da programação junto com um desafio de código que calcula quando ficaria a conta ao dividir com todos da mesa somado com o valor da gorjeta que será dada.

# Aprendizados
- Usar _x:.2f_ (onde x é do tipo *float*) para cortar casas decimais (onde o número após o "."   representa as casas que vem ser mostradas)

- usar "_" em números inteiros para separar visualmente para leitura humanos. Literalmente é apenas para auxiliar leitura humana, o computador ignora e retorna o número inteiro.
