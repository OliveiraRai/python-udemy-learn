# Challenge
Será feito um Higher Lower Game, que consiste em - em jogo - decidir qual das duas figuras públicas que aparecem tem mais seguidores.

# Steps
- criação da variável *game_data* que guardará os dados das figuras públicas FEITO
- criação de duas variáveis que guardarão duas figuras públicas de game_data, e que _não podem se repetir_. (*person1* e *person2*; sim, bem simples.)
    - cada variável deve ser um novo dicionário que guardá cada chave que recebeu de game_data
- criação da variável *guess* onde o player tentará descobrir quem tem mais seguidores: A ou B
- game *loop* onde, _se a tentativa de descoberto for correta: continua; se não: game over._
- se tentativa correta, game score aumenta. Então teremos uma variável *game_score*
