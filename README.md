Início dos estudos de Programação Orientada a Objetos (POO/OOP).

# O QUE É?
É uma forma de modelar objetos do mundo real - classe - e usar o blueprint para criar diversos objetos - objetos - diferentes. Uma classe consiste de atributos, denunciada por um ambiente de variáveis que guardam que atributos tal objeto tem; consiste também de métodos, que se mostra por meio de funcionalidades do objeto (funções). e.g. um carro possui cor e marca, que são atributos; e pode ligar e acelerar, que são métodos.
